# KDBC Coach Tools

A browser-based training builder and boat seating planner for Kingston Dragon Boat Club coaches.

The builder follows the coaching progression:

**Stability → Connection → Timing → Power → Speed**

It uses the KDBC cue-card drill library, selects two or three drills per session,
balances the plan to the selected duration, and includes deliberate race work
only when **Starts / Race** is selected.

Saved practices remain on the current browser and device.

The Boat Planner supports device-only JSON/CSV roster imports, manual roster entry,
drag-and-drop seating for one to four boats, balanced or strongest-first suggestions,
saved lineups, and crew-safe or coach-detail boat cards.

Both consoles provide four working display modes. Training plans print as either a
one-page dockside run sheet or a detailed coaching plan. Boat plans print one boat
per landscape page using a top-down dragon boat layout.
