# KDBC Coach Tools Chrome Extension

This is a lightweight Manifest V3 launcher for the live KDBC Coach Tools app.

## Install locally in Chrome

1. Download or clone this repository.
2. In Chrome, open `chrome://extensions`.
3. Turn on **Developer mode**.
4. Choose **Load unpacked**.
5. Select the `chrome-extension` folder.
6. Pin **KDBC Coach Tools** to the Chrome toolbar.
7. Click the extension icon to open Coach Tools in its own large app-style window.

The extension does not duplicate the coaching application. It opens the live KDBC Coach Tools site, so updates to Stroke Review, Training Builder, and Boat Planner remain centralized.

## PWA installation

The main site is also installable as a Progressive Web App. Open the Coach Tools site in Chrome and use the browser's **Install** option. On iPhone or iPad, open the site in Safari, choose **Share**, then **Add to Home Screen**.
